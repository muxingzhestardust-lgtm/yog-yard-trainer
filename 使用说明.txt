Yog-Sothoth's Yard 外部修改器 使用说明
========================================

适用对象
--------
本包用于 IL2CPP 版《Yog-Sothoth's Yard》，基于 BepInEx 6 插件 + 外部 WinForms UI。

包含文件
--------
winhttp.dll / doorstop_config.ini /   BepInEx 注入器（doorstop）
.doorstop_version / changelog.txt
dotnet\                               BepInEx 所需的 .NET 运行时
BepInEx\core\ 、BepInEx\unity-libs\   BepInEx 6.0.0-be.697 IL2CPP 本体
BepInEx\plugins\ScriptTrainer.dll     游戏内修改器插件
ScriptTrainer.UI.exe                  外部修改器界面
使用说明.txt                          本说明

安装方法
--------
1. 将本包全部内容解压到游戏根目录（与 Yog-Sothoth's Yard.exe 同级）。
   本包已内置匹配版本的 BepInEx 6 IL2CPP 本体（6.0.0-be.697），无需再去
   自行下载 BepInEx，也就不会下错版本；若你此前已自行装过 BepInEx，
   直接合并覆盖即可。
2. 启动游戏。首次带 BepInEx 启动时会在 BepInEx\interop\ 生成互操作程序集，
   停留一到几分钟属正常现象，等游戏窗口正常出现即可（仅首次需要）。
3. 进入一个存档。
4. 运行游戏根目录下的 ScriptTrainer.UI.exe。

推荐目录结构
------------
Yog-Sothoth's Yard\
  Yog-Sothoth's Yard.exe
  ScriptTrainer.UI.exe
  winhttp.dll
  doorstop_config.ini
  dotnet\
  BepInEx\
    core\
    unity-libs\
    plugins\
      ScriptTrainer.dll

使用方法
--------
1. 启动游戏并进入一个存档。
2. 打开 ScriptTrainer.UI.exe。
3. 常用功能页可修改现金、San、灵魂、清洁度、恶值、行动力和角色好感度。
4. 获取物品页可搜索物品名称或 ID，选择物品后点击“添加”。
5. 双击物品列表中的物品也会尝试添加该物品。
6. 如果物品列表为空，点击“导出物品”，或在游戏内进入存档后等待自动导出。
7. 顶栏“背景”按钮可在 20 张游戏 CG 中切换界面背景，选择会记忆在
   ScriptTrainer.UI.skin.cfg；窗口可按住顶栏拖动、拖边缘/角落缩放。
   CG 不随包分发：插件首次随游戏启动时自动提取到 BepInEx\ui_backgrounds\，
   之后背景菜单才会出现可选项（尚未提取时菜单会显示提示）。

特殊物品说明
------------
普通物品通过游戏背包系统添加。
至高遗物/神谕类物品（例如 22000-22018）通过游戏原生遗物创建逻辑处理。
当前版本已修复直接添加至高遗物导致状态污染的问题。
普通神谕（E_Relic，ID 20000-21999，含[特]系列）没有安全的添加通道，直接塞进
背包会损坏存档，本版已主动屏蔽：物品列表不再显示这批物品，按 ID 添加
（包括游戏内 Insert 热键）也会被插件拒绝。[至高]系列 22000+ 不受影响。

热键说明
--------
Home：显示/隐藏游戏内热键模式状态
Ctrl+F12：手动导出物品列表
F1-F10：属性修改热键
F11/F12：调整数量
数字键：输入物品 ID
Insert：按当前 ID 添加物品
End：检查当前 ID 物品

生成的数据文件
--------------
BepInEx\item_ids.csv       物品 ID、名称、类型、图标路径清单
                           （本版第 8-13 列表头改名为 Field_xlf..Field_xlr，
                             与旧版 Field_xla..Field_xlm 同列同义，按列序解析不受影响）
BepInEx\item_icons\        导出的物品图标
BepInEx\ui_backgrounds\    首次启动自动提取的界面背景 CG（含烘焙缓存 baked\）
BepInEx\ScriptTrainer.log  修改器自身日志

注意事项
--------
1. 请先进入存档后再使用修改功能，否则游戏管理器可能尚未初始化。
2. 添加特殊物品后，如果游戏内界面没有立即刷新，可切换页面或重新打开相关界面。
3. 不建议在异常状态下保存游戏。若出现明显 UI/数据异常，请直接退出游戏后重新进入。
4. 修改器通过 BepInEx\ScriptTrainer.commands 和 BepInEx\ScriptTrainer.responses 与游戏通信。
5. 若外部 UI 提示命令无响应，请确认游戏已启动、已进入存档，并且 ScriptTrainer.dll 已加载。

排错方法
--------
1. 查看 BepInEx\ScriptTrainer.log，确认是否有 “ScriptTrainer loaded for IL2CPP.”。
2. 查看 BepInEx\LogOutput.log，确认 BepInEx 是否正常加载插件。
3. 如果物品名称或图标缺失，进入存档后点击 UI 中的“导出物品”。
4. 如果替换 DLL 失败，请先关闭游戏，因为游戏运行时会占用 ScriptTrainer.dll。
5. 若 LogOutput.log 出现大量 “MissingMethodException: Method not found”，
   或 ScriptTrainer.log 出现 “[TRACKER] patch failed/missing”，
   说明游戏又更新并改变了内部混淆名，本修改器需要重新适配，请勿继续使用旧版。

版本兼容性（重要）
------------------
本版修改器只适配 Steam build 24329824（游戏 2026-07-23 更新）及同代版本。
游戏每次更新都可能打乱内部混淆名（如 2026-07-23 更新新增“占卜”功能后整体位移），
旧版修改器在新版游戏上会完全失效（每帧报 Method not found）。
判断游戏版本：steamapps\appmanifest_2194530.acf 中的 "buildid"。
本版已加入自动熔断：若名称失配，只停用受影响功能并写日志，不再每帧刷错误拖垮游戏。

实验性功能页
------------
界面顶栏「实验性功能」页收纳两项实验性功能，默认均不生效，需手动开启：
1. 防回归：开启后，白天/夜晚切换时若 SAN 为 0，不再触发回归结局，而是
   恢复 10 点 SAN，并用游戏原生剧情界面弹出一段耶芙娜的对话（台词随机）。
   开关保存在 BepInEx\ScriptTrainer.experimental.cfg，重启游戏仍生效。
   对应命令：ANTI_REGRESS|1 / 0 / ? / test（test 直接弹一条对话，不改 SAN）。
2. 替换旧版神谕贴图：选择存放旧版 Relic*.png 的目录后点击应用，插件会在
   运行时把这些 PNG 灌回游戏已加载的贴图（仅内存，重启游戏即恢复原样）。
   目录留空时默认使用 BepInEx\relic_override。对应命令：REPLACE_RELIC|<目录>。
